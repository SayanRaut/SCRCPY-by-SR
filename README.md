# SCRCPY PRO CONTROLLER

A high-performance, modern desktop GUI for [Scrcpy](https://github.com/Genymobile/scrcpy) and Android Device Management. Built with PySide6, QtAwesome, and custom Fluent/Cyberpunk styling.

## Features

- **Modern GUI**: A sleek, custom Fluent/Cyberpunk themed interface for managing your Android devices.
- **Easy Device Management**: Connect, view, and control your Android devices seamlessly.
- **Scrcpy Integration**: Fully integrates with Scrcpy for low-latency screen mirroring and control.

## Getting Started

1. Clone the repository.
2. Ensure you have Python installed.
3. Run the compiled executable from the `dist` directory or run the source code directly using:

```bash
pip install -r requirements.txt
python app.py
```

## Build Instructions

To build the executable yourself, you can use PyInstaller:
```bash
python build_exe.py
```
This will compile the application and place the output in the `dist/` folder.
